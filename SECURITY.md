# Reporting a security issue

Email **maintainer@pgoodcode.com** to report a suspected security vulnerability.
Please use email rather than a public issue for details that could put users or
their data at risk.

Include the KeyboardLights version, operating system, a description of the issue,
and steps to reproduce it. Explain the possible impact if you know it. Remove
credentials and personal information from any examples or logs you share.

For ordinary bugs and feature requests, use [GitHub issues](https://github.com/pgoodcodeos/kblights/issues).
