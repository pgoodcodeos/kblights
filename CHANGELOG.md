# Changelog

## 1.0.0

- Initial public release.
- Configure per-key lighting, brightness, and animations with a preview before applying changes.
- Customize key assignments, including shortcuts, mouse actions, and media controls.
- Save and open lighting and assignment profiles.
- Supports legacy Cloud Nine C989 keyboards with firmware 1.38; firmware 1.82 is incompatible.
- Available for macOS 14+ on Apple Silicon and Intel, and Debian/Ubuntu Linux with Python 3.11+ and GTK 4.12+.
